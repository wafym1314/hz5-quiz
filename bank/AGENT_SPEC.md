# 题库文件格式规范（子代理必读）

你正在为小学生每日练网页「惠州小学每日练」扩充题库。仓库根目录：`G:/desktop/惠州五年级每日练`。

## 文件位置与写法
题库文件放在 `G:/desktop/惠州五年级每日练/bank/new/` 目录下。每个文件向全局对象 `QA` 的某个“年级+科目”键 push 题目数组。键名规则：`年级数字 + 科目缩写`，科目缩写：
- `yw` = 语文，`sx` = 数学，`en` = 英语，`sci` = 科学

文件开头必须这样写（以小学语文一年级为例）：

```js
if(!global.QA)global.QA={};
if(!QA["1yw"])QA["1yw"]=[];
QA["1yw"].push(
{i:0,c:"1yw-1",ch:"一上·第1单元 识字（一）",f:0,q:"“天”的读音是？",o:["tiān","tián","tīan","tiǎn"],a:0,k:"拼音：tiān",e:"解析：“天”读 tiān，第一声（阴平）。"},
{i:1,c:"1yw-1",ch:"一上·第1单元 识字（一）",f:1,q:"“上”的反义词是____。",o:[],a:"下",k:"反义词：上—下",e:"解析：“上”的反义词是“下”，表示位置相反。"}
);
```

注意：
- 每个文件只负责一个键（一个年级科目）。例如 `g2yw.js` 负责 `2yw`，`g6sci.js` 负责 `6sci`。
- 文件结尾必须是 `);`（push 调用结束）。
- 不要改其他任何文件，不要 git 提交/推送，不要改 `index_template.html`。

## 每题字段
- `i`：该文件内从 0 开始的连续整数题号（不可重复、不可跳号）。
- `c`：章节代码，如 `"1yw-1"`（年级+科目+章节序号）。同一章节的题目 `c` 相同。
- `ch`：章节标题，显示在 App 里，务必标清上下册，如 `"一上·第1单元 识字（一）"`、`"四下·第3单元 诗歌"`。
- `f`：题型。`0` = 选择题；`1` = 填空题。
- `q`：题干。需要填空处用 `____` 表示。
- `o`：选项数组。`f:0` 时放 4 个字符串；`f:1` 时为空数组 `[]`。
- `a`：`f:0` 时为正确选项的下标（0~3，必须指向 `o` 中真正正确的那一项）；`f:1` 时为正确字符串答案。
- `k`：知识点短语（简短，如 `"拼音：tiān"`、`"修辞手法：比喻"`）。
- `e`：解析，必须以 `"解析："` 开头，讲清为什么该答案正确，最好点出知识点。

## 质量要求
1. **答案必须正确**，`f:0` 的 `a` 下标必须指向 `o` 里真正正确的项。
2. 覆盖该年级对应课本（语文=统编版，数学=人教版，英语=人教PEP，科学=教科版/人教版）上下册主要单元，建议 **8~12 个章节**（`c` 从 1 开始编号），每章 **10~14 题**。选择题为主，每章穿插 1~3 道填空（`f:1`）。
3. 出题前先调研该年级该科目的课本单元与知识点（可用 WebSearch 查“人教版X年级X 教学大纲 / 单元主题”）。
4. 解析要实在、讲知识点，不要空话套话。
5. 选择题选项要有干扰性但合理（不要出现明显荒谬的错误项）。
6. 题干、选项、解析用简体中文；可含拼音（用声调字母，如 tiān）。

## 科学科目额外要求（sci）
- 需要图示的题目，请生成 **SVG 文件** 存到 `G:/desktop/惠州五年级每日练/assets/gNsci/` 目录（例如 `g1sci/plant.svg`），并在该题加字段：
  `img:"https://cdn.jsdelivr.net/gh/wafym1314/hz5-quiz@main/assets/g1sci/plant.svg"`
- SVG 要简单清晰、带中文标注；可先读 `G:/desktop/惠州五年级每日练/assets/g5sci/` 下的示例学习风格（用 Read 工具看 `reflection.svg`、`earthlayers.svg` 等）。
- 每张带 `img` 的题都必须有对应的 svg 文件，文件名与 img 路径一致。
- 配图题目建议每章 1~2 题即可（如结构图、示意图、实验图、食物链、水循环、简单电路等）。
